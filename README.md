# Умный распорядок

Личное приложение для iPhone (PWA) со своим сервером. Что умеет:

- **Пары ТулГУ сами подтягиваются** с сайта `tulsu.ru/schedule` (группа `720043-03`). Сервер проверяет расписание каждые 30 минут и присылает push, если что-то поменялось: отмена, перенос, другая аудитория. Если сайт временно отдаёт пустое расписание (бывает ночью), остаётся последнее сохранённое, и ложных «пара отменена» не приходит.
- **ИИ-планировщик в чате.** Составляет распорядок на неделю, перегенерирует оставшиеся дни или один выбранный день. Принимает пожелания («в среду много работы») и учитывает цели, задачи, приоритеты, дедлайны и переменные.
- **Приоритет задач считается сам** по дедлайну и загруженности: сколько работы осталось и сколько свободного времени есть до срока. Если не успеваешь, приложение предупреждает «не помещается до срока». Приоритет можно поставить и вручную (✋).
- **Автоматическое расписание.** Задачи сами встают в свободные окна по приоритету, срочные идут первыми. Такие дела помечены «🤖 авто». Если поправить такое дело руками, оно становится твоим и больше не двигается. Выключается в «Настройки → Автоматика».
- **Задачи по работе — час в неделю.** Каждой задаче по работе (категория «Работа» или цель «Работа») ставится ровно один час в неделю, на ближайший день со свободным временем. Если день прошёл, а час не отмечен, он переносится на другой день этой же недели с пометкой «↪️ перенесено». ИИ-план эти часы не трогает.
- **Цели по горизонтам:** 5 лет → год → полгода → квартал → месяц → неделя. У каждой цели есть контекст. ИИ разбивает цель на подцели и задачи.
  - **Время на цели.** ИИ считает, сколько часов в неделю нужно каждой цели: по проценту выполнения, сложности, оценкам задач и твоей загруженности. Под это время в расписании ставятся блоки. Часы можно задать вручную.
  - **Постоянные цели** (♾️, например «Работа») — без срока и процента. Время под них заранее не резервируется.
- **Оценка задач.** ИИ оценивает объём, время, сложность и стоимость в монетах. Приложение запоминает, сколько задачи заняли на самом деле (по таймеру ▶), и поправляет будущие оценки под тебя.
- **Переменные как в программировании:** `{дорога_до_вуза} = 40 мин`, `{подъём} = min({обычный_подъём}, {первая_пара} - {дорога_до_вуза} - {сборы})`, `{отбой} = {завтра:подъём} - {сон}`. Их можно создавать в чате и использовать в распорядке.
- **Репетитор.** Вставляешь сообщение из ВК («давай в чт в 18»), и ИИ сам ставит занятие в расписание.
- **Боты ВКонтакте и Telegram.** Пишешь или пересылаешь боту задачи, заметки, сообщения репетитора (прямо из переписки ВК), что съел и что купил. ИИ раскладывает это по приложению, под каждым ответом есть кнопка «Отменить». К целям задачи привязываются, только если попросить об этом явно. Есть команды: «сегодня», «завтра», «задачи» в ВК и `/today`, `/tomorrow`, `/tasks` в Telegram. По желанию — дубль напоминаний в мессенджер. Неоднозначное попадает в «Заметки». Для Telegram, если он недоступен с сервера, можно указать прокси.
- **Переписка → одна задача.** В боте нажимаешь «📥 Собрать задачу», пересылаешь сообщения с картинками и голосовыми и нажимаешь «✅ Готово». Голосовые расшифровывает Yandex SpeechKit, текст с картинок распознаёт Yandex Vision. Нейросеть собирает всё в одну задачу с выжимкой, а картинки сохраняются во вложениях.
- **Оформление.** Три темы: «Классика», «Пастель» и «Неон». Можно выбрать светлый, тёмный или как в iPhone режим и акцентный цвет.
- **Игра без строгостей.** Стартовый баланс 100 🪙, монеты за отмеченные дела (стоимость оценивает ИИ), серия дней с бонусом, магазин своих наград, итоги дня с бонусом. Штрафов нет.
- **Питание по КБЖУ:**
  - текстом через ИИ («гречка 200 г и курица»);
  - вручную уже посчитанные КБЖУ;
  - из встроенной базы примерно на 150 продуктов, она работает без интернета;
  - из недавних записей.

  Норма считается по формуле Миффлина — Сан-Жеора с безопасным дефицитом под цель −15 кг. Вес вносится кнопкой «⚖️» на экране «Еда», есть график веса.
- **Холодильник и рецепты.**
  - ИИ предлагает блюда из того, что есть дома, под оставшееся на день КБЖУ.
  - Продукты тратятся сами: записал в дневник «гречка 200 г», и в холодильнике её стало на 200 г меньше. Приготовленный рецепт тоже списывает ингредиенты.
  - У каждого продукта есть срок годности (ИИ оценивает его сам, можно поправить). Приложение показывает, что скоро испортится и что уже испортилось, и считает, сколько выброшено.
- **Когда идти в магазин и что где купить.** По запасам в холодильнике и норме КБЖУ приложение понимает, когда продукты заканчиваются, и ставит поход в магазин в свободное окно. ИИ составляет список по твоим магазинам (по умолчанию Пятёрочка, Чижик, Перекрёсток; список меняется). Отмечаешь купленное, и оно попадает в холодильник.
- **Продуктовая корзина.** Подбирает самый дешёвый набор продуктов, который закрывает норму КБЖУ на 3–7 дней (линейное программирование). Сейчас цены вносятся вручную, автоматический сбор цен из магазинов — следующий шаг.
- **Работа без интернета.** Данные хранятся в телефоне, приложение открывается офлайн. Нужна сеть только нейросети, а чат копит сообщения и отправит их, когда связь появится. Напоминания можно получать через подписку в «Календаре» iPhone: события и напоминания сохраняются в телефоне и срабатывают даже без интернета.

## Как устроено

```
iPhone (PWA: React + IndexedDB + Service Worker)
   │  синхронизация, ИИ-запросы, расписание, push
   ▼
Сервер (Node.js + SQLite, один Docker-контейнер)
   ├── каждые 30 мин: tulsu.ru → нормализация пар → поиск изменений → push
   ├── /api/ai → YandexGPT (или любой OpenAI-совместимый API)
   ├── напоминания (Web Push) и утренняя сводка
   ├── боты ВКонтакте и Telegram (long polling): входящие → ИИ → задачи/события/еда/заметки
   └── /cal/<секрет>.ics — подписной календарь для iPhone
Caddy — автоматический HTTPS
```

- `server/` — сервер (Express, `node:sqlite`, `web-push`). Тесты: `cd server && npm test`.
- `client/` — приложение (Vite + React + TypeScript). Тесты: `cd client && npm test`.

## Установка

Пошаговая инструкция — **[docs/DEPLOY.md](docs/DEPLOY.md)**: сервер, домен, ключ YandexGPT, установка на iPhone.

## Разработка на компьютере

Нужен Node.js 22.13 или новее.

```bash
cd server && npm install && npm run dev
```

```bash
cd client && npm install && npm run dev
```

`npm run dev` в папке server поднимает сервер на :8080 с паролем `dev` и тестовой нейросетью (`AI_PROVIDER=mock`). `npm run dev` в папке client запускает приложение на http://localhost:5173.

## Сменить нейросеть

В `.env` поменяй `AI_PROVIDER`, ключ и `AI_MODEL`, потом выполни `docker compose up -d`. Поддерживаются:

- `yandex` — YandexGPT, нативный API Yandex AI Studio;
- `openai` — любой OpenAI-совместимый API (DeepSeek, OpenRouter, локальный LM Studio и т.д.);
- `mock` — тестовый режим без ключа.
