# Установка: сервер → YandexGPT → iPhone

На всё уходит около 30–40 минут. Понадобятся:

- сервер (VPS) с Ubuntu 22.04 или 24.04, 1 ГБ памяти — у российских хостингов это около 200–400 ₽ в месяц;
- домен (подойдёт бесплатный, см. шаг 2);
- аккаунт в Yandex Cloud с привязанной картой — для нейросети.

---

## 1. Сервер

1. Купи VPS у любого хостинга. Что выбирать при заказе:

   | Пункт | Что выбрать |
   |---|---|
   | Тип сервера | Обычный, «Стандартный». Hi-CPU не нужен. |
   | Образ диска | **Чистая ОС → Ubuntu 24.04**, можно 22.04. Готовые образы с VPN, панелями и Portainer не нужны. |
   | Конфигурация | 1 ядро, **1–2 ГБ** памяти, 10–20 ГБ диска. При 1 ГБ сделай файл подкачки (см. ниже). |
   | Расположение | Россия, лучше Москва: ближе к Туле, и без проблем открываются сайт ТулГУ и Yandex Cloud. |
   | Автоматическая резервная копия | Можно не включать: данные лежат в телефоне и сами выгрузятся на новый сервер, плюс есть «Резервная копия» в приложении. |
   | Доп. настройки (SSH-ключ, hostname) | Не обязательно. Пароль root придёт на почту. |

   Запиши IP-адрес сервера и пароль root.
2. Подключись с компьютера. В Windows открой PowerShell:

   ```bash
   ssh root@IP_СЕРВЕРА
   ```

3. Установи Docker и git:

   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

   ```bash
   apt-get install -y git
   ```

   Если на российском сервере не скачиваются образы Docker, добавь зеркало (у многих хостингов есть своё, оно указано в их справке) в `/etc/docker/daemon.json`:

   ```json
   { "registry-mirrors": ["https://mirror.gcr.io"] }
   ```

   Затем перезапусти Docker:

   ```bash
   systemctl restart docker
   ```

4. Если у сервера 1 ГБ памяти, добавь файл подкачки на 2 ГБ, иначе сборке приложения может не хватить памяти:

   ```bash
   fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab
   ```

## 2. Домен с HTTPS

iPhone устанавливает веб-приложение и разрешает ему уведомления только по HTTPS, поэтому нужен домен.

- **Бесплатно:** на [duckdns.org](https://www.duckdns.org) войди, например, через GitHub, создай поддомен (`raspisanie` → `raspisanie.duckdns.org`) и впиши в поле *current ip* IP своего сервера.
- **Свой домен** `.ru` стоит около 200 ₽ в год. В DNS добавь A-запись на IP сервера.

Сертификат получит Caddy автоматически при первом запуске.

## 3. Ключ YandexGPT

1. Зайди в [console.yandex.cloud](https://console.yandex.cloud) и создай **платёжный аккаунт** (нужна карта; новым аккаунтам обычно дают стартовый грант).
2. Открой каталог, по умолчанию он называется `default`. Скопируй **ID каталога**: это строка вида `b1g...`, она видна на странице каталога. Это `YANDEX_FOLDER_ID`.
3. Перейди в «Сервисные аккаунты» → «Создать». Назови аккаунт, например, `raspisanie` и выдай роль **`ai.languageModels.user`**.
4. Открой созданный аккаунт → «Создать новый ключ» → **«Создать API-ключ»**. Если спросят область действия, выбери `yc.ai.languageModels.execute`. Скопируй секрет: это `YANDEX_API_KEY`, он показывается один раз.

Модели по умолчанию:

- `yandexgpt/latest` — умная, для плана недели и чата;
- `yandexgpt-lite/latest` — дешёвая и быстрая, для подсчёта еды и оценки задач.

Сколько запросов и токенов ушло за месяц, видно в приложении: **Ещё → Настройки**.

> Хочешь другую нейросеть? В `.env` укажи `AI_PROVIDER=openai`, `OPENAI_BASE_URL`, `OPENAI_API_KEY` и `AI_MODEL`. Подойдёт любой OpenAI-совместимый сервис.

## 4. Запуск

На сервере выполни по очереди:

```bash
git clone https://github.com/ТВОЙ_ЛОГИН/smart-schedule.git
```

```bash
cd smart-schedule
```

```bash
cp .env.example .env
```

```bash
nano .env
```

В `.env` заполни `DOMAIN`, `PUBLIC_URL`, `APP_PASSWORD`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` и сохрани файл (Ctrl+O, Enter, Ctrl+X). Потом запусти:

```bash
docker compose up -d --build
```

Проверь, что всё работает:

```bash
docker compose logs -f app
```

В логе должно появиться `Умный распорядок: http://localhost:8080 (ИИ: yandex, группа 720043-03)`. Открой `https://твой-домен` в браузере, должен появиться экран входа.

**Обновление** после изменений в коде:

```bash
git pull && docker compose up -d --build
```

**Данные** лежат в папке `smart-schedule/data` (SQLite). Сохраняй её копию, а в самом приложении есть «Резервная копия» в Настройках.

## 5. Установка на iPhone

1. Открой `https://твой-домен` **в Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Открой «Распорядок» с рабочего стола и войди с паролем `APP_PASSWORD`.
4. Зайди в **Ещё → Настройки**:
   - **Уведомления → Включить** и разреши их. После этого нажми «Проверить»: должно прийти тестовое уведомление.
   - **Календарь iPhone → Подписаться.** Тогда напоминания о парах и делах будут срабатывать даже без интернета. В настройках подписки выключи «Удалить напоминания».
5. В **Ещё → Переменные** поправь под себя `{дорога_до_вуза}`, `{обычный_подъём}`, `{сон}`.
6. В **Еда → Моя норма** укажи рост, год рождения, целевой вес и внеси текущий вес.
7. Открой **ИИ-чат → «📅 Остаток недели»**, напиши пожелания и нажми «Применить».

## 6. Бот ВКонтакте (необязательно, но удобно)

Бот живёт в сообщениях твоего сообщества ВК. Ему можно писать и пересылать что угодно: задачи, заметки, **сообщения репетитора прямо из переписки**, что съел, что купил. Нейросеть сама разложит это по задачам, расписанию, дневнику питания, холодильнику или заметкам, а под каждым ответом есть кнопка «↩️ Отменить». ВКонтакте работает с российских серверов без ограничений.

1. ВКонтакте → **Сообщества → Создать сообщество**. Тип любой, его можно сделать закрытым, только для себя.
2. В сообществе: **Управление → Сообщения** → включи «Сообщения сообщества». Там же **Настройки для бота → Возможности ботов: Включены**.
3. **Управление → Работа с API** (в разделе «Дополнительно») **→ Ключи доступа → Создать ключ**. Отметь «Управление сообществом» и «Сообщения сообщества», скопируй ключ.
4. Там же вкладка **Long Poll API**: «Включено», версия API **5.199**. Во вкладке «Типы событий» отметь **«Входящее сообщение»** и **«Действие с сообщением»**.
5. Узнай номер сообщества: это цифры в адресе вида `vk.com/club123456789`, их же видно в «Работа с API».
6. На сервере открой настройки:

   ```bash
   nano .env
   ```

   Допиши две строки:

   ```
   VK_GROUP_TOKEN=ключ
   VK_GROUP_ID=123456789
   ```

7. Перезапусти приложение:

   ```bash
   docker compose up -d
   ```

8. В приложении: **Ещё → Настройки → Бот ВКонтакте**. Там появится код из 6 цифр. Нажми «Открыть ВКонтакте», отправь этот код в сообщения сообщества и нажми «Я отправил код».

Команды — просто напиши слово: «сегодня», «завтра», «задачи». В настройках можно включить «Дублировать напоминания во ВКонтакте».

## 7. Telegram-бот (необязательно)

> Если `curl -4 -m 15 https://api.telegram.org/` с сервера отвечает таймаутом, значит, из сети хостинга Telegram недоступен. Тогда используй бота ВКонтакте или подключи прокси, расположенный за границей:
>
> - формат: `TELEGRAM_PROXY=socks5://логин:пароль@IP:порт` или `TELEGRAM_PROXY=http://логин:пароль@IP:порт`;
> - **не подходят** MTProto-прокси (ссылки `tg://proxy…`, `t.me/proxy…` — они только для приложения Telegram) и ключи VPN (`vless://`, WireGuard, Outline);
> - если в пароле есть символы `@ : / #`, замени их на `%40 %3A %2F %23`;
> - проверка прокси с сервера: `curl -x socks5h://логин:пароль@IP:порт -sS -m 15 -o /dev/null -w "%{http_code}\n" https://api.telegram.org/` — ответ `302` значит, что всё работает.

Боту можно писать и пересылать что угодно: задачи («реферат по праву до пятницы»), заметки и идеи, сообщения репетитора («давай в чт в 18»), что съел, что купил. Нейросеть сама разложит это по задачам, расписанию, дневнику питания, холодильнику или заметкам, а всё созданное появится в приложении при синхронизации. Под каждым ответом бота есть кнопка «↩️ Отменить».

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя, потом логин (должен заканчиваться на `bot`, например `tasskes_raspisanie_bot`).
2. Скопируй токен вида `1234567890:AA...`.
3. На сервере открой настройки:

   ```bash
   nano .env
   ```

   Добавь строку `TELEGRAM_BOT_TOKEN=токен` и сохрани файл.

4. Перезапусти приложение:

   ```bash
   docker compose up -d
   ```

5. В приложении: **Ещё → Настройки → Telegram-бот → Подключить**. Откроется Telegram, нажми **«Запустить»**. Бот привязывается только к тебе по одноразовому коду, другим людям он отвечать не будет.

Команды бота: `/today` — план на сегодня, `/tomorrow` — на завтра, `/tasks` — открытые задачи. В настройках можно включить **«Дублировать напоминания в Telegram»**, тогда напоминания о парах и делах будут приходить ещё и в чат с ботом.

### Telegram через свой VLESS-ключ

Если у тебя есть VPN с ключом `vless://…` или ссылкой подписки, на сервере можно поднять маленький VPN-клиент (Xray). Через него пойдёт только бот, остальные программы на сервере работают как обычно.

1. Обнови код и пересобери приложение:

   ```bash
   cd ~/smart-schedule && git pull && docker compose up -d --build
   ```

2. Собери конфиг Xray. В кавычках укажи свою ссылку подписки или ключ `vless://…`, кавычки обязательны:

   ```bash
   mkdir -p xray
   ```

   ```bash
   docker compose run --rm -T --no-deps app node scripts/vless-to-xray.mjs 'ССЫЛКА_ПОДПИСКИ' > xray/config.json
   ```

   Скрипт проверит пинг до каждого сервера из подписки и покажет таблицу. Все рабочие серверы попадут в **автовыбор**: Xray каждые 2 минуты проверяет, через какой сервер Telegram отвечает быстрее, и переключается сам. Если сервер упадёт, Xray перейдёт на следующий.
   Чтобы использовать только один конкретный сервер, допиши его номер из таблицы после ссылки, например `… 'ССЫЛКА' 3 > xray/config.json`.
   Если в подписке поменялись серверы, запусти команду ещё раз и перезапусти Xray: `docker compose restart xray`.

3. Допиши в `.env` две строки:

   ```
   COMPOSE_PROFILES=vpn
   TELEGRAM_PROXY=socks5://xray:10808
   ```

4. Запусти:

   ```bash
   docker compose up -d
   ```

5. Проверь, что Xray запустился без ошибок:

   ```bash
   docker compose logs --tail 20 xray
   ```

   Потом в приложении открой **Настройки → Telegram-бот**: там должно быть «Бот @… готов» и кнопка «Подключить».

Файл `xray/config.json` содержит твой ключ: никому его не отправляй, в GitHub он не попадает. Если VPN-сервис ограничивает число устройств, сервер займёт одно место.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Сайт не открывается | `docker compose ps`: оба контейнера должны быть `running`. Проверь, что домен указывает на IP сервера. |
| Caddy не получает сертификат | Открой порты 80 и 443 в файрволе хостинга. Проверь, что DuckDNS указывает на верный IP. |
| «Нейросеть не настроена» | Заполни `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`, затем выполни `docker compose up -d`. |
| `YandexGPT: ошибка 401/403` | Проверь роль `ai.languageModels.user` у сервисного аккаунта и что ключ создан именно для него. |
| Пары не грузятся | Смотри `docker compose logs app`. Сайт ТулГУ мог быть недоступен; сервер повторит попытку через 30 минут. |
| Не приходят уведомления | Приложение должно быть открыто с экрана «Домой», а не из Safari. Разреши уведомления в Настройках iPhone → Распорядок. |
| Бот не отвечает | Выполни `docker compose logs app \| grep tg`. Проверь токен в `.env`, затем `docker compose up -d`. В настройках приложения должно быть «Бот @… готов». |
| «Нет связи с Telegram» | Проверь с сервера: `curl -4 -sS -m 15 -o /dev/null -w "%{http_code}\n" https://api.telegram.org/`. Ответ `302` значит, что Telegram доступен. Таймаут или сброс соединения значит, что из сети хостинга Telegram недоступен: укажи в `.env` прокси `TELEGRAM_PROXY=http://логин:пароль@хост:порт` или используй бота ВКонтакте. |
